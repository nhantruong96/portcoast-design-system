# Badge

Nhãn trạng thái ngắn, dạng viên thuốc, 1–2 từ; hình viên thuốc chỉ dành cho Badge.

- `tone`: brand, accent, signal, success, warning, danger, neutral; `variant`: soft (mặc định), solid, outline.
- Trạng thái luôn có chữ ("Đạt", "Không đạt"), không chỉ dựa vào màu; thêm `icon` khi cần phân biệt nhanh.
